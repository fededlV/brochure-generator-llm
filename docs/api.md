# API Specification: AI Company Brochure Generator

## Base URL
- Development: `http://localhost:8000`
- Production: `https://<your-domain>`

## Endpoints

### 1. Health Check
Checks backend health and service readiness.

- **URL**: `/api/health`
- **Method**: `GET`
- **Response**:
  ```json
  {
    "status": "ok",
    "version": "1.0.0",
    "gemini_configured": true
  }
  ```

---

### 2. Stream Brochure Generation
Streams real-time generation progress and brochure tokens using Server-Sent Events (SSE).

- **URL**: `/api/generate/stream`
- **Method**: `POST`
- **Headers**:
  - `Content-Type: application/json`
  - `Accept: text/event-stream`

- **Request Body**:
  ```json
  {
    "url": "https://huggingface.co",
    "audience": "investors",
    "tone": "professional",
    "max_subpages": 3
  }
  ```

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `url` | string | Yes | — | Target company URL (must include http/https) |
| `audience` | string | No | `general` | Options: `general`, `prospects`, `investors`, `candidates` |
| `tone` | string | No | `professional` | Options: `professional`, `energetic`, `minimalist` |
| `max_subpages` | integer | No | `3` | Maximum number of subpages to crawl (1 to 5) |

---

### SSE Event Stream Protocol

Events are streamed using standard EventSource format:
```
event: <event_name>
data: <json_string>

```

#### Event: `status`
Emitted at each lifecycle phase.
```json
{
  "step": "crawling_landing",
  "message": "Scraping landing page...",
  "progress": 15
}
```
Possible `step` values:
- `crawling_landing` (15%)
- `analyzing_links` (35%)
- `crawling_subpages` (60%)
- `generating_brochure` (80%)
- `done` (100%)

#### Event: `links_selected`
Emitted when Gemini has selected the most relevant secondary links.
```json
{
  "selected_links": [
    {
      "url": "https://huggingface.co/about",
      "reason": "Contains company mission, team, and background."
    },
    {
      "url": "https://huggingface.co/pricing",
      "reason": "Outlines business model and product tiers."
    }
  ]
}
```

#### Event: `token`
Emitted for each chunk of Markdown brochure generated by the model.
```json
{
  "chunk": "### 1. Executive Summary\n\nHugging Face is the leading collaboration platform..."
}
```

#### Event: `complete`
Emitted when generation has finished successfully.
```json
{
  "status": "completed",
  "total_pages_crawled": 3,
  "elapsed_seconds": 8.4
}
```

#### Event: `error`
Emitted if an unrecoverable error occurs.
```json
{
  "error": "Failed to scrape landing page: connection timed out."
}
```
